## Overview

Miracle POS is the intelligent point-of-sale zone within the Miracle OS ecosystem — built for luxury hotel restaurants, bars, and room service operations.

## Features

- ⚡ **Real-time KOT (Kitchen Order Tickets)** — Orders sync instantly to kitchen displays via WebSocket
- 📱 **Android Tablet App** — Full native Android POS via Capacitor, works offline
- 🧠 **AI Menu Intelligence** — Gemini suggests upsells based on guest profile and time of day
- 📊 **Live Cover Tracking** — Table occupancy, average spend, turn time analytics
- 🔗 **HMS Integration** — Charges post directly to guest folio in Miracle HMS
- 💰 **Multi-payment** — Cash, card, room charge, complimentary — all in one tap
